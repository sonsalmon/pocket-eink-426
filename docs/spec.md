## 3. 두께 적층 (추정)

```
[화면 영역]            앞 테두리 0.8 | 화면 0.93 | 부품 공간 2.0 | 기판 0.8 | 뒷판 0.8  = 5.3 mm
[배터리 영역]          앞 테두리 0.8 | 화면 0.93 | 완충 0.2 | 배터리 3.0~3.2 | 뒷판 0.8 = 5.9 mm
[버튼 띠]              뒷판 0.8 | 기판 0.8 | USB-C 3.26 | 앞판 0.8                     = 5.7 mm
```

기판은 화면 아래쪽 뒤(화면 아래 26 mm)와 버튼 띠에 걸쳐 있고, 배터리는 화면 위쪽 뒤에 나란히 놓입니다. 부품을 겹쳐 쌓지 않아서 전체 두께는 배터리 영역이 정합니다.

## 4. 기판 구성

- 62 × 45 mm, 4층, 두께 0.8 mm. 부품은 모두 앞면(화면 쪽)에만 있어서 JLCPCB 한 면 조립으로 됩니다.
- 층: F.Cu 신호 + GND 채움 / In1 GND / In2 3V3 / B.Cu GND 채움 + 신호.
- 화면 FPC는 유리 끝에서 약 24 mm 나오는 꼬리를 화면 뒤로 180° 접어 기판 위쪽 가운데 FH12 커넥터에 꽂습니다.
- 안테나(칩 안테나 RFANT3216120A5T)는 오른쪽 위 모서리, 7.5 × 11 mm 안에는 구리 채움과 비아를 두지 않습니다.
- 핀 배치는 Xteink X4와 같습니다: EPD SCLK 8 / MOSI 10 / CS 21 / DC 4 / RST 5 / BUSY 6, SD MISO 7 / CS 12, 배터리 ADC 0, 버튼 사다리 ADC 1, 전원 버튼 3, USB 감지 20, SD 전원 스위치 2(Low = 켜짐).
- 버튼 사다리: 10 kΩ 풀업, ◀ 15 kΩ(약 1.98 V), ▶ 6.8 kΩ(약 1.34 V), ● 0 Ω(0 V). FreeInk SDK의 OnePage 전압 창과 맞춥니다.

## 5. 에이전트가 정한 기술 결정

| 결정 | 이유 | 틀리면 드는 비용 |
| --- | --- | --- |
| ESP32-C3 칩 직접 실장 (모듈 대신) | 16 MB 플래시가 필요한데 두께 2.4 mm 이하 모듈(MINI-1)은 4 MB뿐. X4도 같은 구성 | Wi-Fi 거리가 짧으면 안테나 정합 부품(C3·R2·C4) 값 조정. 기판 재주문 없이 납땜으로 해결 가능 |
| X4와 같은 핀 배치 | CrossPoint의 X4 드라이버와 검증된 설정을 그대로 씀 | 없음 (보드 설정 한 곳만 추가) |
| 버튼 3개를 한 ADC 사다리로 | GPIO 절약, SDK에 이미 있는 판정 코드 재사용 | 저항 오차로 오판정이 나면 저항 값 변경 |
| ● 길게 = 뒤로(SDK에서 합성) | 뒤로 버튼이 없어도 CrossPoint 메뉴 전체를 쓸 수 있음 | 길게 누름 기준(650 ms)이 불편하면 상수 한 줄 수정 |
| 보호회로 DW01A + FS8205A를 기판에 둠 | 보호회로 없는 셀을 사도 안전. 부품값 약 $0.1 | 없음 |
| SD 카드 전원을 P-FET로 차단 | SD 대기 전류(수백 µA)가 대기 수명을 좌우함 | 펌웨어가 전원 핀을 못 쓰면 0 Ω으로 우회 |
| 회로도·기판을 `design.py` 하나에서 생성, 배선은 Freerouting 자동 | KiCad가 없는 환경에서도 재현 가능, 회로도와 기판이 어긋나지 않음 | 자동 배선이 RF·승압 회로에 최적은 아님 → 주문 전 사람이 KiCad에서 확인 |
| 하드웨어 CERN-OHL-W-2.0, 펌웨어 MIT | 참고한 IS7V4N 기판과 CrossPoint의 라이선스를 따름 | 없음 |

## 6. 주문 전에 반드시 확인할 것

1. 화면 FPC: 꼬리 길이, 가운데 정렬 여부, 접점이 어느 면에 있는지, 1번 핀이 어느 쪽인지. 실물이나 도면으로 확인한 뒤 `design.py`의 `FPC_OPENING_Y`와 J2 위치·방향을 맞춥니다. (Good Display 사양서 PDF는 로그인이 필요해 이번에 받지 못했습니다.)
2. KiCad에서 기판을 열어 RF 선(ESP32 LNA_IN → R2 → 안테나)과 승압 회로(L1·Q3·D2~D4) 배선을 눈으로 확인합니다.
3. 케이스 도면은 아직 없습니다. 기판·화면·배터리 치수가 확정되면 만듭니다.
